# اتجاه واجهات Scan4Dent

## المنتج والجمهور

نظام تشغيل لمركز أشعة الأسنان. الاستقبال يسجل حالات بسرعة على الهاتف، والفني يرفع النتائج، والطبيب يقرأ الملفات، والمدير يراجع الفروع والحسابات والزيارات. المهمة الرئيسية: إنشاء حالة ثم معرفة المطلوب لإنجازها ومشاركتها.

## بحث المهارات ومراجعة ملاءمته

تم تشغيل ui-ux-pro-max للاستعلام `radiology clinic operations dashboard` ثم إعادة محاولة أضيق `internal operations dashboard`. النتيجة الأولى اقترحت Claymorphism وخطوطًا غير مناسبة للمحتوى العربي وشاشة التشغيل؛ الثانية اقترحت Minimalism مع هيكل صفحة تسويقية. لم يوجد تطابق موثوق لتخطيط هذا المنتج؛ التخطيط التالي تصميم مخصص، مع اعتماد إرشادات الوصول العامة كمرجع بديل. بحث Laravel عن `authorization forms validation` أعطى إرشادات مناسبة: حفظ المدخلات عند الخطأ، رسائل قرب الحقول، فصل التحقق والصلاحيات.

## الخطوط والقياسات

- Readex Pro للنص والحقول، Alexandria للعناوين فقط؛ كلاهما موجود في المشروع.
- نص النموذج 16px / line-height 1.6، النص الثانوي 14px، العناوين 22–28px.
- أرقام بخصائص tabular-nums واتجاه LTR معزول. DM Mono للرموز التقنية فقط، لا لكل التسميات.
- كثافة الجدول للشاشة الكبيرة مع مساحة لمس 44px على الهاتف، هوامش 16–24px، نموذج عمود واحد على الهاتف.

## تنظيم الشاشة

Dashboard يبدأ بالفرع والتاريخ والإجراء «حالة جديدة». تليه قائمة العمل المطلوبة اليوم، ثم ملخصات وإحصائيات الإدارة حسب الدور. لا يسبق طابور الحالات رسم زخرفي أو رسالة ترحيب كبيرة.

```text
Desktop RTL (right sidebar)
+------------------------------------------------+------------------+
| الفرع / الفترة                     حالة جديدة | التنقل           |
| الجديدة  قيد التنفيذ  المكتملة  حالات اليوم   | الحالات          |
|                                                | المرضى           |
| قائمة الحالات + البحث + مرشحات                 | الحسابات*        |
| الحالة | المريض | الفحص | الفني | المطلوب      | الزيارات*        |
|                                                | الإدارة*         |
| ملخص مالي*    توزيع الفروع / الفحوصات*          |                  |
+------------------------------------------------+------------------+
* حسب الدور والصلاحية

Mobile case creation
+-------------------------------+
| حالة جديدة                   |
| ابحث عن مريض / سجل بياناته    |
| الاسم (اختياري)               |
| العمر       سنة الميلاد       |
| الهاتف (اختياري)              |
```

ملف المريض: معلومات مختصرة، ثم حالات مرتبة بالتاريخ. كل حالة تعرض فحصها وحالة العمل ومجموعات الملفات و«مشاركة الحالة». تفاصيل الفيديو والملفات والمشاركة تنتمي إلى الحالة المحددة حتى داخل ملف المريض.

## ما يجعل الواجهة مناسبة للمركز

- الإشارة المميزة الوحيدة إلى غرفة الأشعة هي شريط التنقل وحاوية عرض الملفات الداكنة. تبقى النماذج فاتحة وسهلة القراءة.
- أولوية الحالات التي تنتظر الفني أو الملفات، مع إجراء واضح لكل صف.
- زر أساسي واحد للتسجيل؛ البحث عن مريض سابق وإنشاء مريض جديد جزء من نفس تدفق الحالة.
- بيانات الفرع ثابتة للمستخدم المقيد؛ المدير لديه مرشح جميع الفروع.
- سعر أساسي وخصم ونهائي ظاهرون جنبًا إلى جنب لمن يحق له تسجيل السعر، وملخص تحصيل اليوم وفق الدور.

## مراجعة قبل التنفيذ

تم تعديل الفكرة الحالية: إزالة الترحيب الكبير والأشعة الزخرفية من لوحة التشغيل لأن التسجيل والمتابعة أهم، تقليل بطاقات الأرقام المتكررة، وإظهار طابور الحالات قبل المخططات. نحتفظ بألوان وخطوط المشروع لتطوير هوية المركز الموجودة.

معيار التسليم: RTL صحيح، ترتيب لوحة المفاتيح منطقي، focus ظاهر، labels حقيقية، أخطاء قرب الحقول مع الحفاظ على المدخلات، تباين نص 4.5:1، reduced-motion، تقدم الرفع وأخطاء قابلة لإعادة المحاولة، وعدم عرض الحسابات أو بيانات فرع غير مصرح به حتى في البيانات المرسلة للمتصفح.
