# Scan4Dent — إدارة مركز الأشعة

MVP عربي RTL: المرضى والحالات والفروع، أربعة أدوار وصلاحيات فردية، أسعار الفحوصات والخصومات، حسابات يومية وشهرية، زيارات الأطباء، ملفات وفيديو على Google Drive، روابط مشاركة مرتبطة بالحالة، سجل حركات ومحذوفات قابلة للاسترجاع.

## التشغيل

النسخة المحلية الحالية: **http://localhost:8011**. Laravel 13 / PHP 8.3+، Livewire 4، Flux، Tailwind 4، Readex Pro وAlexandria، SQLite محليًا.

للمشروع الموجود دون إعادة زرع البيانات:

```bash
composer install
php artisan migrate
npm install
npm run build
php artisan serve --host=127.0.0.1 --port=8011
php artisan queue:work --tries=5 --timeout=1800
```

للتثبيت الجديد فقط: انسخ `.env.example` إلى `.env`، أنشئ `APP_KEY` باستخدام `php artisan key:generate`، وجهّز قاعدة البيانات ثم migrate. بيانات العرض الاصطناعية اختيارية باستخدام `php artisan db:seed` على قاعدة جديدة. لا تستخدم `migrate:fresh` أو seeding على قاعدة المركز القائمة. توجد نسخة محلية قبل التوسعة: `database/database.pre-mvp-20261001.sqlite`.

## البداية

1. افتح «المستخدمون والصلاحيات» وحدد فرع كل استقبال وفني. الحساب القديم غير المسند إلى فرع لا يرى بيانات أي فرع.
2. حدد العملة في «إعدادات المركز» قبل تسجيل الأسعار، ثم أسعار الفحوصات والأسعار الخاصة بالفروع. القيم القديمة غير المسعّرة تُعرض كـ«غير مسعّرة».
3. اربط Drive واتبع [دليل الإعداد](docs/google-drive-setup.md). يحتاج الإنتاج Queue worker وcron كل دقيقة. الملفات الجديدة افتراضيًا إلى Drive؛ `CASE_UPLOAD_PROVIDER=local` مخصص للتطوير بدون اتصال Google.
4. «حالة جديدة» تسجل مريضًا جديدًا أو تربط مريضًا سابقًا. الاسم والهاتف والطبيب ونوع الفحص اختيارية؛ السجل ناقص الهوية مريض مستقل يمكن استكماله لاحقًا. العمر والسنة مرتبطان ويستخدم تاريخ 01/01 داخليًا عند التسجيل بالسنة.

العملة غير محددة في النسخة الحالية، والمنطقة الزمنية الافتراضية `Africa/Cairo` ويمكن تغييرها بـ`APP_TIMEZONE`. حسابات اليوم تعتمد منطقة التطبيق الزمنية. اضبطها قبل تسجيل تحصيلات حقيقية.

## الأدوار

| الدور | التشغيل | الحسابات |
|---|---|---|
| Manager | كل الفروع وإدارة كاملة، أكثر من مدير مسموح | كل الفترات والفروع، رد مبالغ بأثر محفوظ |
| Reception | مرضى وحالات فرعه، رفع ومشاركة؛ الخصم/الزيارات بصلاحية إضافية | يوم العمل الحالي بفرعه فقط |
| Doctor | حالات الطبيب المسندة إليه داخل فروعه، ملفات وتقارير وملاحظات | محجوبة دائمًا |
| Technician | حالات مسندة إليه بفرعه، ملفات وملاحظات وحالة الفحص | محجوبة دائمًا |

الصلاحيات الفردية تمنح/تمنع داخل حدود الدور والفرع. إدارة المستخدمين والحذف وإدارة الأسعار العامة والفروع تظل للمدير. لا يمكن تحويل الطبيب أو الفني إلى مستخدم مالي بواسطة override. ملفات Drive تمر عبر صلاحيات النظام، وروابط المشاركة تسمح فقط بملفات الحالة المختارة والجاهزة. WhatsApp يفتح مسودة رسالة؛ لا توجد API إرسال تلقائي.

## المال والحذف

الأسعار أعداد صحيحة بأصغر وحدة نقدية. يُحفظ السعر الأساسي والنهائي والخصم والسبب والمنفذ والوقت. التحصيل دفتر مستقل، والمقبوض يختلف عن قيمة الفحوصات. إعادة نفس طلب التحصيل لا تنشئ دفعة جديدة، والرد إضافة سالبة تحتفظ بالدفع الأصلي. CSV يستخدم نطاق صلاحيات التقرير نفسه.

الحذف العادي للمريض والحالة والملف Soft Delete. المدير يسترجعها من «المحذوفات»؛ لا تُحذف الملفات الأصلية. استرجاع الأب يعيد فقط أبناء عملية الحذف نفسها، ويظل رابط الحالة ملغيًا حتى إصدار رابط جديد. الحسابات والسجل محفوظان.

| الدور | الهاتف |
|---|---|
| Manager | 01000000001 |
| Reception | 01000000002 |
| Doctor | 01000000003 / 01000000004 / 01000000005 |
| Technician | 01000000006 |

لا تُستخدم بيانات العرض في الإنتاج. التوسعة لا تعيد إنشاء مستخدمي قاعدة البيانات القائمة.
